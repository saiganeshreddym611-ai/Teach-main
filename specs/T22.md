# T22 — Retriever (node-linked + BM25)

## Goal

Two ways to find passages:

- `for_node(node_id)`: the passages a node cites through its `source_refs`. Deterministic.
  **Grading uses only this** (rule 6).
- `search(query)`: BM25 keyword search with a confidence in [0, 1], for student questions and
  practice lookup. A low confidence later means "outside the syllabus material" (T42).

Pure Python, no new dependency, deterministic ordering, and a calibration script that suggests the
confidence threshold.

## Code

### `tutor/retrieval/text.py`

```python
TOKEN_RE = re.compile(r"[a-z0-9]+")
STOPWORDS: frozenset[str]
    # A fixed list in this module: common English function words (a, an, the, of, to, in, is,
    # are, what, how, why, when, which, ...) plus question filler: explain, tell, please,
    # describe, mean, means, meaning, define, definition, understand, know, give, help, want,
    # need, example, examples. Never numbers, never "para".

class Normaliser:
    """Rewrites synonym variants to one canonical phrase, identically for passages and queries.
    synonyms.json format: {"<canonical phrase>": ["<variant>", ...]}, for example
    {"standalone selling price": ["ssp", "stand alone selling price"]}."""
    def __init__(self, synonyms: dict[str, list[str]]) -> None: ...
    def tokens(self, text: str) -> list[str]:
        """1. TOKEN_RE.findall(text.lower())  ("B28" -> "b28", "stand-alone" -> "stand", "alone")
        2. Replace variant token sequences with the canonical phrase's tokens: longest variant
           first, scanning left to right, no overlaps.
        3. Drop STOPWORDS."""
    @property
    def sha256(self) -> str: ...     # sha256 of json.dumps(synonyms, sort_keys=True, ensure_ascii=False), for cache keys

def load_synonyms(pack: ContentPack) -> dict[str, list[str]]:
    """pack.root / "synonyms.json", or {} if missing."""
```

### `tutor/retrieval/bm25.py`

```python
class BM25Index:
    K1 = 1.5
    B = 0.75

    def __init__(self, docs: list[list[str]]) -> None:
        """docs[i] is the token list of document i."""
    def idf(self, term: str) -> float:
        """ln(1 + (N - df + 0.5) / (df + 0.5)). A term in no document has the highest idf."""
    def score(self, query_terms: list[str], i: int) -> float:
        """Standard BM25 over the unique query terms."""
    def confidence(self, query_terms: list[str], i: int) -> float:
        """idf-weighted query coverage: sum(idf(t) for unique t in query that occur in doc i)
        / sum(idf(t) for unique t in query). 0.0 for an empty query. Always in [0, 1].
        Chosen because it does not depend on the other results, so it is stable across queries,
        and words the corpus has never seen (for example 'leases', 'gst') pull it down hard."""
```

### `tutor/retrieval/retriever.py`

```python
@dataclass(frozen=True)
class SearchFilters:
    doc_types: frozenset[str] | None = None
    attempt: str | None = None          # passage.attempt must equal this
    chapter: str | None = None          # passage.chapter must equal this
    node_ids: frozenset[str] | None = None   # only passages for_node() returns for these nodes

class Retriever(Protocol):
    def for_node(self, node_id: str) -> list[Passage]: ...
    def search(self, query: str, k: int = 5, filters: SearchFilters | None = None) -> list[ScoredPassage]: ...

class PackRetriever:
    """Retriever over one pack's corpus. The BM25 index is built once per corpus."""
    def __init__(self, corpus: Corpus, normaliser: Normaliser) -> None: ...

    def for_node(self, node_id: str) -> list[Passage]:
        """Resolve the node's source_refs in order, concatenate, drop repeats (keep the first).
        An UnresolvedRef is skipped and logged with logging.warning (validate_pack reports it).
        Unknown node_id -> KeyError."""

    def search(self, query: str, k: int = 5, filters: SearchFilters | None = None) -> list[ScoredPassage]:
        """Apply filters first. Score every remaining passage; keep score > 0; sort by
        (-score, passage_id); return the top k as ScoredPassage(passage, score, confidence)."""

def get_retriever(pack: ContentPack) -> PackRetriever | None:
    """None when the pack has no corpus. Cached per (pack.root, corpus_sha256, synonyms sha256),
    so a rebuilt corpus or changed synonyms gives a new index."""
```

### `scripts/calibrate_retrieval.py`

```
python scripts/calibrate_retrieval.py --pack fixture_115 --packs-dir tests/fixtures/packs \
    [--queries tests/evals/retrieval/queries.jsonl] [--k 5] [--min-recall 0.8] [--json]
```

`queries.jsonl`, one object per line:
`{"id": "in01", "pack": "fixture_115", "query": "...", "in_syllabus": true, "expected": ["IndAS115.para.9"]}`.
Out-of-syllabus lines have `"in_syllabus": false, "expected": []`. Only lines whose `pack`
matches `--pack` are used.

Computes:

- `recall_at_k`: mean over in-syllabus queries of `|expected ∩ top-k IDs| / |expected|`.
- `top1_confidence` per query (0.0 when there is no result).
- `threshold`: candidates are the midpoints between consecutive distinct top-1 confidences.
  Choose the one with the highest accuracy (in-syllabus if confidence ≥ threshold); break ties by
  the largest distance to the nearest confidence, then by the lowest value.
- `accuracy` at that threshold, and `margin` = lowest in-syllabus top-1 confidence minus highest
  out-of-syllabus top-1 confidence (negative means they overlap).

Prints a per-query table and the summary, or one JSON object with `--json`. Returns 1 if
`recall_at_k < --min-recall`, else 0. Has `main(argv: list[str] | None = None) -> int` and a
`calibrate(retriever, queries, k) -> dict` function that tests call directly.

## Tests

`services/tutor/tests/test_retriever.py` (new), on the fixture pack.

| Test | Asserts |
|---|---|
| `test_tokens` | `"What is para B28 of the Standard?"` gives `["para", "b28", "standard"]`. |
| `test_synonyms_both_sides` | A query with `wup` finds the passage that says `widget unit price`, and the reverse; both sides normalise the same way. |
| `test_for_node_order_and_dedupe` | A node with overlapping refs returns each passage once, in ref order then document order. |
| `test_for_node_unknown` | Unknown node ID raises `KeyError`. |
| `test_search_deterministic` | The same query twice returns identical lists. |
| `test_ties_broken_by_id` | A `PackRetriever` over two passages with identical text returns them ordered by `passage_id`. |
| `test_filters` | `doc_types={"rtp"}` returns only RTP passages; `attempt`, `chapter` and `node_ids` each restrict results as specified. |
| `test_confidence_range_and_extremes` | Every confidence is in [0, 1]; a query of only unseen words returns no results; a query whose terms all occur in one passage gives that passage confidence 1.0. |
| `test_recall_at_5` | `calibrate(...)["recall_at_k"] >= 0.8` on the fixture queries. |
| `test_out_of_syllabus_below_threshold` | Every out-of-syllabus query's top-1 confidence is below the suggested threshold, and every in-syllabus one is at or above it. |
| `test_retriever_cache` | `get_retriever(pack)` twice returns the same object; on a tmp copy whose corpus was rebuilt with an extra paragraph, it returns a new one. |
