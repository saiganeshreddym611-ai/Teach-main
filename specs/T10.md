# T10 — Content pack layout and loader

## Goal

Move the concept map into a versioned content pack (`content/packs/ind_as_115/`) and load it
through a pack loader, so exam content becomes data that can be swapped without code changes.
The tutor's behaviour and the grader's prompt must stay **byte-identical**.


### `tutor/content.py` (new)

```python
PACKS_DIR = Path(__file__).resolve().parents[3] / "content" / "packs"

class ContentPackError(RuntimeError):
    """A content pack is missing or invalid. The message says what to fix."""

@dataclass(frozen=True)
class ContentPack:
    pack_id: str
    root: Path                    # content/packs/<pack_id>
    manifest: PackManifest
    curriculum: Curriculum
    content_hash: str             # see compute_content_hash

    @property
    def concept_map_path(self) -> Path: ...   # root / "concept_map.json"
    @property
    def reviews_path(self) -> Path: ...       # root / "reviews.json"   (T11)
    @property
    def releases_path(self) -> Path: ...      # root / "releases.json"  (T11)
    @property
    def sources_path(self) -> Path: ...       # root / "sources" / "sources.json"  (T20)
    @property
    def corpus_dir(self) -> Path: ...         # root / "corpus"  (T20)

def available_packs(packs_dir: Path | None = None) -> list[str]:
    """Sorted names of sub-folders of packs_dir that contain manifest.json."""

def load_pack(pack_id: str | None = None, packs_dir: Path | None = None) -> ContentPack:
    """Load and validate a pack. pack_id defaults to settings.content_pack; packs_dir defaults to
    the module-level PACKS_DIR, read at call time (so tests can monkeypatch it). Cached per
    (pack_id, packs_dir) with functools.lru_cache on a private helper."""

def clear_pack_cache() -> None:
    """Clear the load_pack cache. Tests call this after changing settings or files."""

def compute_content_hash(manifest: PackManifest, tree: Tree) -> str:
    """sha256 hex of json.dumps({"manifest": manifest.model_dump(mode="json"),
    "concept_map": tree.model_dump(mode="json")}, sort_keys=True, separators=(",", ":"),
    ensure_ascii=False).encode("utf-8").
    Covers every field, including chapter. Never includes reviews.json or releases.json.
    T50 and T71 will add skills, tasks and practice items to it."""
```

`load_pack` raises `ContentPackError` (never a bare `KeyError` or `ValidationError`) when:

| Problem | Message must include |
|---|---|
| Pack folder or `manifest.json` missing | `Unknown CONTENT_PACK '<id>'. Available: <comma-separated list>` |
| `manifest.json` or `concept_map.json` fails validation | the file path and the Pydantic error text |
| `manifest.pack_id` differs from the folder name | both names |
| `concept_map.json` `topic_id` not in `manifest.topics` | the topic ID |
| Duplicate node IDs, or a `parent` that is not a node ID | the offending node IDs |

### `tutor/curriculum.py`

- Delete `CURRICULUM_DIR`.
- Keep the `Curriculum` class API unchanged, except `stable_json`:

```python
PROMPT_TREE_FIELDS = ("topic_id", "subject", "standard", "opening_prompt")
PROMPT_NODE_FIELDS = ("id", "level", "parent", "title", "rubric", "misconceptions",
                      "canonical_explanation", "example", "source_refs")

    def stable_json(self) -> str:
        """Byte-stable serialisation for the cached prompt prefix. Only prompt-relevant fields:
        review and chapter metadata never enter the prompt."""
        # model_dump(include=...) with PROMPT_TREE_FIELDS plus {"nodes": {"__all__": PROMPT_NODE_FIELDS}},
        # then json.dumps(..., sort_keys=True, ensure_ascii=False, indent=1) exactly as today.
```

- `load_curriculum(topic_id: str) -> Curriculum` keeps its signature. It imports `load_pack`
  inside the function (to avoid a circular import, since `content.py` imports `Curriculum`),
  loads the active pack, and returns `pack.curriculum` if `topic_id` equals
  `pack.curriculum.tree.topic_id`. Otherwise it raises
  `FileNotFoundError(f"No curriculum for topic '{topic_id}' in content pack '{pack.pack_id}'")`
  (the existing 404 test depends on `FileNotFoundError`). Remove its own `lru_cache`; the pack is
  cached.

## Tests

`services/tutor/tests/test_content_pack.py` (new). Tests that load other packs build them under
`tmp_path` and pass `packs_dir=tmp_path`; call `clear_pack_cache()` in a fixture before and
after each test.

| Test | Asserts |
|---|---|
| `test_stable_json_matches_golden` | `load_curriculum("ind_as_115").stable_json()` equals the golden file's text (normalise `\r\n` to `\n` on the file side). |
| `test_node_ids_unchanged` | The pack has 42 nodes and the same node IDs, in the same order, as the golden file. |
| `test_chapter_not_in_prompt` | `"chapter"` does not appear in `stable_json()`, but every node has a non-empty `chapter`. |
| `test_load_pack_default` | `load_pack().manifest.attempt == "2027-05"`, `content_hash` is 64 hex chars, and two calls return the same object. |
| `test_content_hash_changes_with_content` | A tmp copy of the pack with one rubric line changed has a different `content_hash`. |
| `test_unknown_pack` | `load_pack("nope")` raises `ContentPackError` whose message contains `Available:` and `ind_as_115`. |
| `test_invalid_packs` | Parametrised over the problems in the table above (built in `tmp_path`): each raises `ContentPackError`. |
| `test_unknown_topic_still_404` | `load_curriculum("nope")` raises `FileNotFoundError`. |
| `test_content_endpoint` | `GET /content` returns 200 with `manifest.pack_id == "ind_as_115"` and the pack's `content_hash`. |
