## Case schema (all new keys optional; existing cases unchanged)

```json
{
  "name": "...", "pack": "ind_as_115", "status": "reviewed",
  "focus_node_id": null, "prior_context": "", "transcript": "...",
  "expect": {"<node_id>": "VERIFIED | PARTIAL | GAP | NOT_MENTIONED | !VERIFIED"},
  "expect_citations": {"<node_id>": ["IndAS37.para.14"]},
  "expect_omissions": ["<level-1 node_id>"]
}
```

- `pack` defaults to `ind_as_115`. `status` defaults to `reviewed`; new cases are `draft`.
- `expect_citations`: each listed value is a prefix. It passes when each prefix matches at least
  one of that node's verdict `passage_ids`, in every run.
- `expect_omissions`: the level-1 node IDs from `omissions()` must equal this list as a set.
  Diagnostic cases only.

## run_evals.py

1. Group cases by `pack`. For each pack:
   - set `settings.content_pack`, then `clear_pack_cache()`;
   - clear the `get_grader` cache and the grade memo;
   - take the curriculum from `load_pack()`.
   Restore the original pack at the end.
2. Draft cases run and print, marked `[DRAFT]`, but do not count toward the failure total or the
   exit code unless `--include-drafts` is given.
3. Put the checks in pure functions, so they are testable without a model:
   - `check_citations(expect, runs) -> list[str]`, which returns failure lines;
   - `check_omissions(expect, curriculum, runs) -> list[str]`.
4. Keep `--repeat`, `--only`, `--memo` and the citation-diff report from T32.

## Tests (`tests/test_eval_cases.py`, no model calls)

| Test | Asserts |
|---|---|
| `test_every_case_is_valid` | Each case parses, the node IDs exist in its pack, `status` is `draft` or `reviewed`, cited prefixes match at least one passage ID in that pack's corpus, and `expect_omissions` are level-1 IDs. |
| `test_check_citations` | A matching prefix passes, a missing one fails, and a mismatch in one of three runs fails. |
| `test_check_omissions` | Set equality with a scripted `GraderOutput`. |
| `test_drafts_do_not_count` | The failure count excludes drafts unless `include_drafts=True`. |
