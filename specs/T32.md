## Contracts

```python
# config.py
grader_capture_dir: Path = Path(os.getenv("GRADER_CAPTURE_DIR", str(<services/tutor>/"data"/"captures")))
capture_grader_calls: bool = os.getenv("CAPTURE_GRADER_CALLS", "1") in {"1", "true", "yes"}
grade_memo: bool = os.getenv("GRADE_MEMO", "1") in {"1", "true", "yes"}

# Grader protocol and all graders (Claude, Ollama, Mock, MemoGrader, ScriptedGrader)
async def grade(self, curriculum, transcript, *, focus_node_id, prior_context, session_id,
                student_id: str = "", call_id: str | None = None) -> GraderOutput

# grader_audit.py
def new_call_id() -> str                      # uuid4().hex
def sha256_text(text: str) -> str
def memo_key(backend: str, prompt_version: str, system_text: str, user_text: str) -> str
class GradeMemo:                              # in-memory, at most 1024 entries, oldest dropped
    def get(self, key) -> tuple[GraderOutput, str] | None   # (deep copy, original call_id)
    def put(self, key, output: GraderOutput, call_id: str) -> None
    def clear(self) -> None
grade_memo = GradeMemo()
def write_capture(record: dict) -> None       # <grader_capture_dir>/<grader_call_id>.json; never raises
def citation_diffs(runs: list[GraderOutput], node_ids: Iterable[str]) -> list[str]

# grading_links.py
def offered_passage_ids(curriculum, links, focus_node_id=None) -> list[str]  # the block's ids, in order
```

## Rules that are not obvious

1. `memo_key` is SHA-256 of `json.dumps([backend, prompt_version, sha256(system_text),
   sha256(user_text)])`. `system_text` is the joined text of `_system_blocks(...)` and `user_text` is
   `_user_content(...)`. They embed the tree, passages, instructions, focus, prior context and
   transcript, so any content or prompt change is a miss. Read `prompts.PROMPT_VERSION` at call time
   (module attribute), so tests can monkeypatch it.
2. `MemoGrader.grade`: `call_id = call_id or new_call_id()`. If `settings.grade_memo` is false, call
   the inner grader. On a hit, return the stored copy and write a capture with `memo_hit: true`,
   `memo_of: <original id>`, no usage. On a miss, call the inner grader with the same `call_id`,
   then `put`. Store only successful results.
3. The capture record (Claude, Ollama and Mock all write one; Mock has `usage: null`) contains:
   `grader_call_id, ts, session_id, student_id, phase ("diagnostic" | "teach_back"),
   focus_node_id, focus_rubric, provider, model, request_id, prompt_version, content_hash,
   system_sha256, offered_passage_ids, input, output, corrections, latency_ms, usage, memo_hit,
   memo_of`. `latency_ms` times the model call only. Skip the write when
   `capture_grader_calls` is false.
4. `Curriculum.__init__(self, tree, content_hash: str | None = None)`. `_load_pack` passes
   `compute_content_hash(manifest, tree)`.
5. The state machine creates `call_id = new_call_id()` per grade. It passes
   `student_id=session.student_id` and `call_id`, then
   `append_verdicts(..., grader_call_id=call_id)`, which sets `LedgerEvent.grader_call_id`.
6. `run_evals.py` turns the memo off unless `--memo` is given. For each expected node it compares
   `passage_ids` across `--repeat` runs, prints each `citation_diffs` line as `  [CITE] ...`, and
   ends with `N failing expectation(s), M inconsistent citation(s) ...`. Exit 1 if N or M > 0.
7. `scripts/grader_usage.py [--dir PATH]` exposes `summarise(records) -> dict[phase, totals]`. The
   totals are `calls, memo_hits, input, cache_read, cache_write, output, mean_latency_ms`.
   - Claude keys: `input_tokens`, `cache_read_input_tokens`, `cache_creation_input_tokens`,
     `output_tokens`.
   - Ollama keys: `prompt_eval_count` counts as input, `eval_count` as output.
   - Print a plain table.
8. The conftest autouse fixture points `settings.grader_capture_dir` to `tmp_path` and calls
   `grade_memo.clear()`.

## Tests (`tests/test_grader_audit.py`)

| Test | Asserts |
|---|---|
| `test_memo_hit_skips_second_call` | Counting inner grader, two identical calls: inner called once; equal outputs; 2 capture files; the second has `memo_hit` true and `memo_of` equal to the first ID. |
| `test_memo_miss_on_changed_input` | Changing the transcript, focus or prior context makes a new inner call. |
| `test_memo_miss_on_prompt_version` | Monkeypatched `PROMPT_VERSION` makes a miss. |
| `test_memo_miss_on_content_change` | A curriculum with one rubric line changed makes a miss. |
| `test_memo_disabled` | `grade_memo=False`: two inner calls. |
| `test_memo_returns_copy` | Mutating a returned output does not change the next hit. |
| `test_capture_has_audit_fields` | `OllamaGrader` with the fake client writes `<call_id>.json` with `student_id`, `prompt_version` "2", `content_hash`, 64-hex `system_sha256`, `offered_passage_ids`, `corrections`, `latency_ms`, `phase`. |
| `test_capture_disabled` | No file when `capture_grader_calls=False`. |
| `test_offered_ids_match_block` | Fixture pack: the ids from a regex over the `passages_block` text equal `offered_passage_ids`. |
| `test_citation_diffs` | Same status and different passage ids give one line naming the node; identical runs give `[]`. |
| `test_ledger_events_carry_call_id` | Diagnostic via `ScriptedGrader`: every event's `grader_call_id` equals the `call_id` the grader received. |
| `test_grader_usage_totals` | Claude, Ollama and memo-hit records sum correctly per phase. |
