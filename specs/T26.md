## Contracts

```python
# config.py
retrieval_mode: str = os.getenv("RETRIEVAL_MODE", "bm25").lower()   # bm25 | hybrid
hybrid_weight: float = float(os.getenv("HYBRID_WEIGHT", "0.5"))      # weight of the vector score
embed_model: str = os.getenv("EMBED_MODEL", "")                       # "" = the model in vectors_manifest.json

# vectors.py
class Embedder(Protocol):
    name: str
    def embed(self, texts: list[str]) -> list[list[float]]: ...      # unit-length vectors
class OllamaEmbedder:  # ollama.Client(host=settings.ollama_host).embed(model=..., input=texts)
class HashEmbedder:    # name "hash-256": deterministic hashed bag of words, 256 dims, no model (mock)
class VectorIndex:
    model: str
    def similarity(self, query_vector: list[float], passage_id: str) -> float   # cosine clamped to [0, 1]
def build_vectors(corpus: Corpus, embedder: Embedder, batch: int = 16) -> dict[str, list[float]]
def write_vectors(pack: ContentPack, vectors: dict[str, list[float]], embedder: Embedder, corpus: Corpus) -> None
def load_vectors(corpus: Corpus) -> VectorIndex | None
def get_embedder(model: str) -> Embedder          # "hash-256" gives HashEmbedder, anything else Ollama
```

## Rules that are not obvious

1. **Files.**
   - `corpus/vectors.jsonl` has one line per passage, sorted by `passage_id`:
     `{"passage_id": ..., "vector": [...]}`, with each float rounded to 6 decimals.
   - `corpus/vectors_manifest.json` holds `{model, dim, corpus_sha256, count}`.
   - Write UTF-8 with LF line endings and a final newline.
2. **Stale vectors.** `load_vectors` returns `None` and logs a warning when the files are missing,
   the manifest's `corpus_sha256` differs from the corpus, or any passage has no vector. Search
   then uses BM25 alone.
3. **Hybrid search** runs only when `retrieval_mode == "hybrid"` and vectors are loaded:
   - Embed the query once with `get_embedder(settings.embed_model or index.model)`.
   - Every passage that passes the filters is a candidate, including passages with a BM25 score
     of 0. This is the point: paraphrases share no words.
   - `score = w * similarity + (1 - w) * bm25_confidence`, with `w = hybrid_weight`, and
     `confidence = score`.
   - Keep candidates with `score > 0`, sort by `(-score, passage_id)`, and return the top `k` as
     `ScoredPassage`. Every result is a passage from the corpus.
4. **Failure.** If the query embedding raises (Ollama down), log a warning and return the BM25
   results. Search never crashes because of the embedder.
5. **`bm25` mode** gives exactly today's results. Existing tests pass unchanged.
6. **Choose the model by measurement.**
   - Candidates: `nomic-embed-text` and `embeddinggemma`. Pull them with `ollama pull <name>`.
   - For each candidate, build `ind_as_37` vectors and run `calibrate_retrieval.py --pack ind_as_37`
     with `--mode bm25` and with `--mode hybrid`, on all questions and with `--reworded-only`.
     Record recall@5, accuracy and margin in a README table.
   - Commit the vectors of the best model (highest reworded recall; on a tie, the smaller model).
   - Leave the default `RETRIEVAL_MODE=bm25`: the owner switches it after the audit.
7. **Reworded questions.** Each line has `"pack": "ind_as_37"` and `"reworded": true`. It is phrased
   the way a student speaks and shares few words with the paragraph. `expected` holds the
   paragraph IDs whose text answers it; read `chunks.jsonl` and never guess.

## Tests (`tests/test_hybrid_retrieval.py`, no model calls)

Use `fixture_115` (the `tests/test_retriever.py` pattern), copied to `tmp_path` when writing files,
and a `DictEmbedder` defined in the test that maps known texts to fixed vectors.

| Test | Asserts |
|---|---|
| `test_hash_embedder_deterministic_unit_length` | The same text gives the same vector; the norm is 1 (±1e-6). |
| `test_write_and_load_vectors` | The files are sorted, rounded to 6 decimals, and hold the manifest fields; `load_vectors` returns an index. |
| `test_stale_vectors_ignored` | A changed `corpus_sha256` in the manifest makes `load_vectors` return `None`. |
| `test_hybrid_finds_zero_overlap_match` | With `DictEmbedder`, a query sharing no words with its passage ranks that passage first in hybrid mode and does not find it in bm25 mode. |
| `test_hybrid_deterministic_and_ids_only` | Two searches return identical lists; every result's `passage_id` is in the corpus. |
| `test_bm25_mode_unchanged` | In `bm25` mode, results equal `PackRetriever.search` without vectors. |
| `test_embed_failure_falls_back` | An embedder that raises gives the BM25 results and no exception. |
