# T20 — Ingestion pipeline

## Goal

Turn a pack's source documents into a corpus of passages (`corpus/chunks.jsonl`) with stable IDs
such as `IndAS115.para.76`, so every citation can resolve back to a source passage. Output is
deterministic: the same input gives byte-identical files. Until the owner supplies real sources
(H1), only a synthetic fixture pack has a corpus.

## Source text conventions

Real sources will be converted to text in this format before ingestion (H1). The fixture pack
follows it too.

- UTF-8 (a BOM is stripped). Line endings are normalised to `\n`.
- A **block** is a run of non-blank lines. Blocks are separated by one or more blank lines.
- A form feed `\f` marks a page break. Page numbers start at 1 and count form feeds before the
  line. Remove `\f` from the text. If a document has no `\f`, `page` is `None`.
- Markdown headings (`#`, `##`, `###` at the start of a line, followed by a space) are headings.
  A heading is always its own line; the lines after it in the same block are an ordinary block.
- Passage text is the lines of its blocks, each right-stripped, joined with `\n`, with blank
  lines removed and the whole text stripped. Nothing else is changed: text stays verbatim.

### Splitter interface

```python
@dataclass(frozen=True)
class SplitContext:
    paper: str        # pack manifest paper
    attempt: str      # doc.attempt, else the pack manifest attempt

Splitter = Callable[[SourceDoc, str, SplitContext], list[Passage]]
SPLITTERS: dict[DocType, Splitter]   # every DocType has an entry
```

Each splitter returns passages in document order. `passage_id = f"{doc.doc_code}.{locator}"`,
`doc_id`, `doc_type`, `attempt` and `version` come from the doc and context, and
`sha256 = sha256(text.encode("utf-8")).hexdigest()`.

### `standard` splitter (`tutor/ingest/standard.py`)

- A new paragraph starts at a block whose first line matches
  `^(?P<num>(?:IE|B|C)?\d{1,3}[A-Z]{0,2})\.?\s+\S` (for example `9`, `27A`, `B28`, `IE3`, `C1`).
  Only the **first line of a block** can start a paragraph, so a wrapped line that begins with a
  number (for example `10 per cent of ...`) never splits one.
- Any other block is appended to the current paragraph (sub-items `(a)`, `(b)`, continuation
  text). Blocks before the first paragraph are preamble: skipped and counted in a warning.
- A heading ends the current paragraph and sets `section` (heading text without `#`) for the
  following paragraphs.
- `locator = f"para.{num}"`. The paragraph number stays in the text.
- `chapter = ""`. `page` is the page of the paragraph's first line.

### `amendment` splitter

Same as `standard`, plus: a line inside a paragraph that starts with `Supersedes:` is removed
from the text, and its comma-separated passage IDs become `supersedes`.

### `study_material` splitter (`tutor/ingest/study_material.py`)

- `#` heading starts chapter `n`: the number from `Chapter\s+(\d+)` in the heading if present,
  otherwise a counter (1, 2, ...). Sets `chapter` to the heading text. Resets the section counter.
- `##` heading starts section `m` (1, 2, ... within the chapter). Sets `section`. Text in a
  chapter before its first `##` is section `0`.
- `###` and deeper headings are kept as text lines inside the section.
- Within a section, blocks are packed into chunks in order. Before adding a block, if the chunk
  is not empty and the chunk plus the block would exceed `MAX_WORDS = 350` words
  (`len(text.split())`), close the chunk. A single block longer than 350 words is its own chunk
  (never split mid-block) and adds a warning. A chunk never crosses a section or chapter.
- `locator = f"ch{n}.s{m}.p{k}"` with `k` = 1, 2, ... within the section.
- Text before the first `#` heading is skipped and counted in a warning.

### `qa` splitter (`tutor/ingest/qa.py`) for `rtp`, `mtp`, `past_paper`

- A question starts at a block whose first line matches
  `^(?:Question|QUESTION|Q(?=\s*\d))\s*(?P<n>\d+)\s*[.:)]?(?:\s+|$)`.
- An answer starts at a block whose first line matches
  `^(?:Answer|ANSWER|Ans\.|A(?=\d))\s*(?P<n>\d+)?\s*[.:)]?(?:\s+|$)`. Without a number, it
  answers the last question. These patterns are case-sensitive on purpose, so a sentence such as
  `A company sells ...` is never an answer marker.
- Other blocks are appended to the current question or answer.
- `locator = f"q{n}"` or `f"q{n}.ans"`. `section = f"Q{n}"`. An answer with no number before any
  question raises `IngestError`.

### `tutor/ingest/pipeline.py`

```python
class IngestError(RuntimeError): ...

def build_corpus(pack: ContentPack, *, check_hashes: bool = True) -> tuple[list[Passage], CorpusManifest, list[str]]:
    """For each SourceDoc in sources.json order: read pack.root / doc.path, check its sha256
    (mismatch -> IngestError telling the user to update sources.json; empty sha256 -> warning
    with the actual hash), split with SPLITTERS[doc.doc_type], and collect passages.
    Duplicate passage_ids -> IngestError listing every duplicate.
    A doc_code missing from manifest.doc_codes -> warning.
    Returns (passages, manifest, warnings)."""

def write_corpus(pack: ContentPack, passages: list[Passage], manifest: CorpusManifest) -> None:
    """Write pack.corpus_dir / "chunks.jsonl": one line per passage,
    json.dumps(p.model_dump(mode="json"), sort_keys=True, ensure_ascii=False,
    separators=(",", ":")) + "\n", UTF-8, "\n" newlines.
    Write pack.corpus_dir / "manifest.json": manifest, indent=2, sort_keys=True, trailing newline.
    corpus_sha256 is the sha256 of the exact chunks.jsonl bytes. No timestamps anywhere."""
```

### `scripts/ingest.py`

```
python scripts/ingest.py --pack <id> [--packs-dir DIR] [--no-hash-check]
```

Prints passages per document, every warning, `chunk_count` and `corpus_sha256`. On
`IngestError` or `ContentPackError`, prints the message to stderr and returns 1. Has
`main(argv: list[str] | None = None) -> int`.
