# T11 — Review gate

## Goal

Every content item (concept node now; tasks and practice items later) carries a review status
bound to a hash of its content. Editing an item sends it back to `draft`. Strict mode refuses to
teach unless every item in scope is usable and the pack has a release sign-off for its current
content. Two scripts let a human produce the sign-off report and record their checks.

This task builds the **gate and the records**. It does not review anything; the Claude review
pipeline is T23, and it will write through the functions defined here.

## Code

### Files in a pack

- `reviews.json`: `{item_id: ReviewMeta}`, keys sorted, `indent=2`, `ensure_ascii=False`,
  trailing newline. Missing file means every item is `draft`.
- `releases.json`: `[ReleaseSignoff]` in the order recorded, same formatting. Missing file means
  no release.
- Neither file is part of `content_hash` (T10), so recording a review never changes the hash.

### `tutor/review.py` (new)

```python
ItemKind = Literal["node", "task", "practice"]
KIND_GROUPS: dict[ItemKind, str] = {"node": "nodes", "task": "tasks", "practice": "practice"}
REGRESSIONS_PATH = Path(__file__).resolve().parents[1] / "tests" / "evals" / "review" / "regressions.jsonl"

class ReviewGateError(RuntimeError):
    """A review or audit action is not allowed. The message says why."""

def canonical_sha256(data: BaseModel | dict | list) -> str:
    """sha256 hex of json.dumps(data (model_dump(mode="json") for models), sort_keys=True,
    separators=(",", ":"), ensure_ascii=False) encoded as UTF-8."""

def pack_items(pack: ContentPack) -> dict[str, tuple[ItemKind, dict]]:
    """item_id -> (kind, item JSON). Today: every concept node (node.model_dump(mode="json")).
    T50 adds tasks and skills; T71 adds practice items."""

def item_hashes(pack: ContentPack) -> dict[str, str]:
    """item_id -> canonical_sha256(item JSON). The node hash covers every node field, including
    chapter."""

def load_reviews(pack: ContentPack) -> dict[str, ReviewMeta]: ...
def save_reviews(pack: ContentPack, reviews: dict[str, ReviewMeta]) -> None:
    """Write reviews.json atomically (write a temp file in the same folder, then os.replace)."""

def load_releases(pack: ContentPack) -> list[ReleaseSignoff]: ...

def effective_status(item_id: str, current_hash: str, reviews: dict[str, ReviewMeta]) -> ReviewStatus:
    """"draft" when there is no review, or its content_sha256 differs from current_hash.
    Otherwise the review's status."""

def status_table(pack: ContentPack) -> dict[str, tuple[ItemKind, ReviewStatus]]:
    """item_id -> (kind, effective status), for every item in the pack."""

def review_counts(pack: ContentPack) -> dict[str, dict[str, int]]:
    """{"nodes": {...}, "tasks": {...}, "practice": {...}}. Every group has all four statuses,
    zero-filled, in the order draft, claude_reviewed, needs_expert, signed_off."""

def current_release(pack: ContentPack) -> ReleaseSignoff | None:
    """The last release whose content_hash == pack.content_hash and version ==
    pack.manifest.version, else None."""

def strict_problems(pack: ContentPack) -> list[dict]:
    """What blocks strict mode. One {"item_id", "kind", "status"} per item whose status is not in
    USABLE_REVIEW_STATUSES, sorted by item_id, then {"item_id": "<release>", "kind": "release",
    "status": "missing"} if current_release(pack) is None. Empty list = usable."""

def sample_for_signoff(pack: ContentPack, seed: int | None = None) -> tuple[int, list[str]]:
    """Reproducible sample of claude_reviewed items for the human check.
    candidates = sorted IDs whose effective status is claude_reviewed.
    size = min(len(candidates), max(10, ceil(0.10 * len(candidates)))).
    seed defaults to int(pack.content_hash[:8], 16).
    Returns (seed, sorted(random.Random(seed).sample(candidates, size)))."""

def record_pass(pack: ContentPack, item_ids: list[str], by: str, note: str = "") -> None:
    """Human check passed. Each item must exist and have effective status claude_reviewed or
    needs_expert (an expert may clear a needs_expert item). Sets status "signed_off",
    signed_off_by=by, signed_off_at=UTC now, appends note to notes. Raises ReviewGateError, and
    changes nothing, if any item fails the check."""

def record_error(pack: ContentPack, item_ids: list[str], by: str, note: str) -> None:
    """Human check found an error. note is required. Each item is set to "draft" with its current
    hash (creating a ReviewMeta if none exists), and "[audit error <YYYY-MM-DD> by <by>] <note>"
    is appended to notes. Appends one line per item to REGRESSIONS_PATH:
    {"pack_id", "kind", "item_id", "content_sha256", "item", "note", "by", "at"}
    (sort_keys=True, ensure_ascii=False). T23 uses this file as the reviewer's regression set."""

def record_release(pack: ContentPack, by: str, scope_note: str = "") -> ReleaseSignoff:
    """Release sign-off for the pack's current content. Raises ReviewGateError listing the
    items if any item's status is not usable. Otherwise appends
    ReleaseSignoff(pack_id, version=manifest.version, content_hash=pack.content_hash,
    signed_off_by=by, signed_off_at=UTC now, scope_note) to releases.json and returns it."""
```

`notes` are appended as new lines, never overwritten.

### `scripts/review_sheet.py` (new)

```
python scripts/review_sheet.py --pack ind_as_115 [--packs-dir DIR] [--seed N] [--out FILE]
```

- Default `--out`: `services/tutor/data/reviews/<pack_id>-<version>-review-sheet.md`
  (create folders; `data/` is gitignored). Prints the output path.
- The report is deterministic: the same pack, reviews and seed give byte-identical output. No
  timestamps.
- Sections, in this order:
  1. `# Review sheet: <pack_id> <version>` with exam, paper, attempt, `content_hash`, and the
     release sign-off (who and when) or `No release sign-off for this content`.
  2. `## Counts`: a table of `review_counts`.
  3. `## Needs expert`: every `needs_expert` item, as an item block.
  4. `## Sample for sign-off (seed <seed>, <size> of <n>)`: the `sample_for_signoff` items, as
     item blocks.
  5. `## Not yet reviewed`: `draft` items as a bullet list of `id — title`.
- Item block: `### <id> — <title>`, then status, reviewer mode and model, a table of claims
  (`claim | verdict | passage | quote | quote verified`), and notes. Pipes in text are escaped.

### `scripts/record_audit.py` (new)

```
python scripts/record_audit.py --pack ind_as_115 --by "Name" --pass ITEM [ITEM ...] [--note TEXT]
python scripts/record_audit.py --pack ind_as_115 --by "Name" --error ITEM [ITEM ...] --note TEXT
python scripts/record_audit.py --pack ind_as_115 --by "Name" --release [--scope-note TEXT]
```

- `--pass`, `--error` and `--release` are mutually exclusive; one is required. `--by` is
  required. `--packs-dir` is optional, as in `review_sheet.py`.
- Calls `record_pass`, `record_error` or `record_release`. Prints one line per change.
- On `ReviewGateError`, prints the message to stderr and exits with code 1.
- Module docstring: "Records a human check. Only a person runs this against a real pack; coding
  agents and review pipelines never do."

### `tutor/main.py`

- `POST /session`: after the topic is found, if `settings.require_reviewed_content` and
  `strict_problems(load_pack())` is not empty, raise
  `HTTPException(409, detail={"message": "Content is not approved for use.", "problems": <list>})`.
- `GET /content`: fill `review_counts`.
- `GET /health`: add
  `"content": {"pack_id", "version", "content_hash", "review_counts", "release_signed_off": bool, "strict": bool}`.

  `# 1 refuses to teach unless every item is reviewed and the release is signed off.`

`services/tutor/tests/test_review_gate.py` (new). Every test builds its pack in `tmp_path`,
monkeypatches `REGRESSIONS_PATH` to `tmp_path`, and calls `clear_pack_cache()` before and after.
API tests monkeypatch `tutor.content.PACKS_DIR` and `settings.content_pack` (and
`settings.require_reviewed_content`) and post the fixture `topic_id`.

| Test | Asserts |
|---|---|
| `test_new_pack_is_all_draft` | No `reviews.json`: every node is `draft`; counts `{"draft": 3, ...}` with all four keys in all three groups. |
| `test_review_valid_while_hash_matches` | A `claude_reviewed` review with the current hash gives `claude_reviewed`. |
| `test_edit_invalidates_review` | After changing one rubric line in `concept_map.json` (and clearing the cache), that node is `draft`; the others keep their status. |
| `test_recording_review_keeps_content_hash` | `pack.content_hash` is the same before and after `save_reviews` and `record_release`. |
| `test_strict_refuses_draft` | Strict on, all draft: `POST /session` returns 409; `problems` lists 3 nodes and the missing release. |
| `test_strict_refuses_needs_expert` | One `needs_expert`, others `claude_reviewed`, release recorded before the flip: 409 lists that node. |
| `test_strict_refuses_without_release` | All `claude_reviewed`, no release: 409 with only the `release` problem. |
| `test_strict_allows_reviewed_and_released` | All usable, release recorded: 200. |
| `test_release_bound_to_content` | After a release, editing a node makes `current_release()` return `None`. |
| `test_dev_mode_allows_drafts` | Strict off, all draft: 200. |
| `test_sample_size_and_reproducibility` | 30 `claude_reviewed` items: size 10; 150 items: size 15; 4 items: size 4; the same seed gives the same list twice. |
| `test_record_pass` | Passing a `claude_reviewed` item sets `signed_off`, `signed_off_by`, `signed_off_at`. |
| `test_record_pass_refuses_draft` | Passing a `draft` item raises `ReviewGateError` and changes no file. |
| `test_record_error` | The item becomes `draft`, notes contain `audit error`, and one line is added to the regression file with the item's JSON. |
| `test_release_refuses_unusable` | `record_release` with a `draft` item raises `ReviewGateError` naming it. |
| `test_review_sheet_order_and_determinism` | Run `review_sheet.main([...])` twice: identical bytes; the `needs_expert` item appears before the sample section. |
| `test_record_audit_cli_exit_code` | `record_audit.main([... "--pass", "<draft id>"])` returns 1. |
