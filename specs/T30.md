## Where the code is today

- `tutor/grader.py`: `ClaudeGrader` (`messages.parse` into `GraderResult`), `OllamaGrader`
  (temperature 0, JSON schema from `GraderResult`), `MockGrader` (keyword overlap), and
  `_finalise()`, which filters verdicts to the curriculum.
- `tutor/prompts.py`: `tree_block()` (cached), `GRADER_INSTRUCTIONS`, `PROMPT_VERSION = "1"`.
- `tutor/contracts/grading.py`: `GraderOutput {claims[], verdicts[], summary}`, `Claim`,
  `NodeVerdictV2` (with `rubric_items_met`, `misconception_ids`, `citation_origin`),
  `ClaimJudgment`. Defined in T02, unused so far.
- Callers: `state_machine.py` (DIAGNOSTIC with no focus, TEACH_BACK with a focus node).

## Plan

1. **Passages block.** `prompts.passages_block(pack)`: every passage any node links to (T22
   `for_node`), in node order then document order, each as `<passage id="...">text</passage>`,
   cached after the tree block. Instructions stay after the cache breakpoint. Measure tokens; above
   about 30k, teach-back calls send only the focus node's passages, and the decision goes in the
   Open Questions log. Until H1 the real pack has no corpus, so the block is empty there and
   grading behaves as today.
2. **Instructions.** Rewrite `GRADER_INSTRUCTIONS`: split speech into claims; judge each only
   against the passages and rubric; per verdict list rubric items met, misconceptions matched and
   supporting passage IDs; flag off-syllabus claims without grading them. Keep every existing
   strictness rule word for word, including "name-dropping is not evidence".
3. **All three graders emit `GraderOutput`.** Claude via `messages.parse`; Ollama via its schema
   and an updated `OLLAMA_OUTPUT_CONTRACT`; Mock emits one claim per matched node with
   `node_link` citations.
4. **`_finalise()` v2:** drop passage IDs outside the node's linked set; when a graded verdict has
   none, attach the node's first linked passage with `citation_origin="node_link"`; drop
   out-of-range rubric and misconception indexes; count every correction for the audit log (T32).
5. **Omissions:** after a diagnostic, code lists every L1 node with no evidence, with its node
   citations. The `grade` SSE event gains `claims` and `omissions`.
6. Adapt `state_machine.py` and the ledger writes to the new shape. Bump `PROMPT_VERSION` to "2".
