# T82 — Voice verification mock endpoint

## Goal

Expose `POST /verify` so the kiosk (later) can check that the enrolled student is the one
speaking (FR-9). For now the only backend is the stub, which always matches. The point is a
stable interface and a conformance test that any real verifier must pass later.

### `tutor/integrity.py`

Keep `VerificationResult`, `SpeakerVerifier` and `StubVerifier` as they are. Add:

```python
VERIFIERS: dict[str, type[SpeakerVerifier]] = {"stub": StubVerifier}

class UnknownVerifierError(ValueError):
    """SPEAKER_VERIFIER names no registered verifier. Message lists the valid names."""

@lru_cache(maxsize=1)
def get_verifier() -> SpeakerVerifier:
    """Instance for settings.speaker_verifier. Raises UnknownVerifierError for unknown names."""

def describe_verifier() -> str:
    """The configured verifier name, e.g. "stub"."""
```

### `tutor/main.py`

```python
@app.post("/verify", response_model=VerifyResponse)
async def verify(req: VerifyRequest) -> VerifyResponse:
    ...
```

Behaviour:

1. Decode `req.audio_b64` with `base64.b64decode(..., validate=True)`. Invalid base64 or empty
   decoded audio returns **422** with a short message.
2. Call `await get_verifier().verify(req.student_id, audio)`.
3. Return `VerifyResponse(match=..., score=..., method=...)`.
4. Never write the audio to disk, logs or the session store. Drop the reference after the call.
5. `UnknownVerifierError` returns **500** with its message.

Add `"verifier": describe_verifier()` to the `/health` response.

## Tests

`services/tutor/tests/test_verify.py` (new).

The conformance test is parametrised over `VERIFIERS`, so every verifier added later must pass it.

| Test | Asserts |
|---|---|
| `test_verifier_conformance[<name>]` | For each registered verifier: `enroll` returns `None`; `verify` returns a `VerificationResult` with `isinstance(match, bool)`, `0.0 <= score <= 1.0`, non-empty `method`; two calls with the same input give the same result. Use 1 second of 16 kHz silence as the audio. |
| `test_verify_endpoint_ok` | `POST /verify` with a valid body returns 200 and `{"match": true, "score": 1.0, "method": "stub"}`. |
| `test_verify_bad_base64` | `audio_b64="not base64!!"` returns 422. |
| `test_verify_bad_student_id` | `student_id="a b"` returns 422. |
| `test_unknown_verifier` | With `settings.speaker_verifier = "nope"` (monkeypatch, then `get_verifier.cache_clear()`), `get_verifier()` raises `UnknownVerifierError` whose message contains `stub`. Clear the cache again after the test. |
| `test_health_reports_verifier` | `/health` has `"verifier": "stub"`. |
