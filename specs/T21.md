# T21 — Source-ref resolver and passage API

## Goal

Resolve every `source_refs` value in a concept map (for example `IndAS115.para.B28-B33`) to the
corpus passages it points at, format citation labels ("Ind AS 115, paras 76–77"), serve a
passage by ID, and give the owner a validator that fails when any node cites a passage that does
not exist.

## Code

### `tutor/retrieval/corpus.py`

```python
class Corpus:
    def __init__(self, pack: ContentPack, passages: list[Passage], sources: list[SourceDoc],
                 corpus_sha256: str) -> None: ...
    pack: ContentPack
    corpus_sha256: str
    by_id: dict[str, Passage]
    docs: dict[str, SourceDoc]            # doc_id -> doc
    order: dict[str, list[str]]           # doc_id -> passage IDs in document (file) order

    def passage(self, passage_id: str) -> Passage: ...            # KeyError if unknown
    def doc(self, doc_id: str) -> SourceDoc: ...
    def doc_for_code(self, doc_code: str) -> SourceDoc | None:
        """manifest.doc_codes[doc_code] if present and in docs; else the single doc with that
        doc_code; else None."""

def load_corpus(pack: ContentPack) -> Corpus | None:
    """None if corpus/chunks.jsonl is missing. Reads corpus/manifest.json for corpus_sha256.
    Cached per (pack.root, corpus_sha256); a rebuilt corpus is picked up automatically."""
```

### `tutor/retrieval/refs.py`

```python
PARA = r"(?:IE|B|C)?\d{1,3}[A-Z]{0,2}"
REF_RE = re.compile(rf"^(?P<doc>.+?)\.para\.(?P<start>{PARA})(?:-(?P<end>{PARA}))?(?P<sub>(?:\([a-z0-9]{{1,4}}\))*)$")

@dataclass(frozen=True)
class SourceRef:
    raw: str
    doc_code: str
    start: str            # "22", "B28"
    end: str | None       # "33", "B33", or None for a single paragraph
    sub: str              # "(b)" or ""

class UnresolvedRef(LookupError):
    def __init__(self, ref: str, reason: str) -> None: ...   # str(e) == f"{ref}: {reason}"

def parse_ref(ref: str) -> SourceRef | None:
    """SourceRef for a paragraph ref, None for anything else (treated as an exact passage ID)."""

def resolve_ref(ref: str, corpus: Corpus) -> list[Passage]:
    """1. ref is a passage ID in the corpus -> [that passage].
    2. paragraph ref -> doc = corpus.doc_for_code(doc_code) (else UnresolvedRef "unknown document
       code"). Single: the passage f"{doc.doc_code}.para.{start}". Range: every passage of that
       doc from start to end inclusive, in document order (so 27A between 27 and 28 is
       included). "(b)" resolves to the whole paragraph 22.
       Missing start or end -> UnresolvedRef naming the missing ID. End before start ->
       UnresolvedRef "range is reversed".
    3. anything else -> UnresolvedRef "no such passage"."""

def cite_ref(ref: str, corpus: Corpus) -> Citation:
    """Citation(passage_id=first resolved passage, label=ref_label(...), doc_id)."""

def cite_passage(passage: Passage, corpus: Corpus) -> Citation: ...

def ref_label(ref: str, corpus: Corpus) -> str: ...
def passage_label(passage: Passage, doc: SourceDoc) -> str: ...
```

Labels. `name = doc.short_name or doc.title`. The range dash is an en dash (U+2013).

| Doc type | Input | Label |
|---|---|---|
| standard, amendment | `IndAS115.para.76` | `Ind AS 115, para 76` |
| standard, amendment | `IndAS115.para.76-77` | `Ind AS 115, paras 76–77` |
| standard, amendment | `IndAS115.para.22(b)` | `Ind AS 115, para 22(b)` |
| study_material | `ICAI.SM.FR.ch4.s2.p3` | `ICAI Study Material, Ch 4 §2` (section 0: `..., Ch 4`) |
| rtp / mtp / past_paper | `RTP.2025-05.q3.ans` | `RTP May 2025, Q3 (answer)`; prefix `RTP`, `MTP` or `Past paper`; attempt `YYYY-MM` shown as month name and year; omitted when the doc has no attempt |

### `scripts/validate_pack.py`

```
python scripts/validate_pack.py --pack <id> [--packs-dir DIR]
```

- No corpus: prints `No corpus for <id>: run scripts/ingest.py first` and returns 2.
- Resolves every ref of every node, in node order. Prints `OK: <n> refs across <m> nodes resolve`
  and returns 0, or prints one line per failure (`<node_id>  <ref>  <reason>`) and returns 1.
- Has `main(argv: list[str] | None = None) -> int`.

## Tests

(`load_pack("fixture_115", packs_dir=<tests/fixtures/packs>)`). Tests that edit files copy the
pack to `tmp_path` first. Call `clear_pack_cache()` around tests that change settings.

| Test | Asserts |
|---|---|

| `test_resolve_single_range_sub` | On the fixture: `para.9-11` gives 3 passages in order; `para.22(b)` gives `para.22`; `para.B28-B30` gives 3; `IndAS37.para.66-69` gives 4. |
| `test_range_uses_document_order` | `IndAS115.para.11-27A` gives `11`, `22`, `27A`. |
| `test_resolve_exact_id` | `ICAI.SM.FR.ch1.s1.p1` gives that passage. |
| `test_unresolved` | Parametrised: a missing paragraph, an unknown doc code, a reversed range, and `nonsense` each raise `UnresolvedRef` with a reason. |
| `test_labels` | The five label formats in the table above, on the fixture docs: `Ind AS 115, para 9`, `Ind AS 115, paras 9–11`, `Ind AS 115, para 22(b)`, `ICAI Study Material, Ch 1 §1`, `RTP January 2099, Q1 (answer)`. |
| `test_passage_endpoint` | With the fixture pack active: `GET /passages/IndAS115.para.9` returns 200 with passage, source and citation; an unknown ID returns 404. |
| `test_validator_passes_on_fixture` | `validate_pack.main([...fixture...])` returns 0. |
| `test_validator_fails_on_broken_ref` | A tmp copy with one ref changed to `IndAS115.para.999` returns 1. |
