## The flow (code decides every step)

1. **New target node** (`_advance_to_next_node`): `phase = INSTRUCT`, `instruct_step = "PROBE"`,
   `instruct_turns_on_node = 0`. The directive `PHASE=INSTRUCT ACTION=PROBE` replaces today's
   `INTRODUCE_NODE`. It keeps the preface (study mode, "previous node verified" and so on) and:
   - names the first rubric item not yet met, from the latest ledger event for this node in the
     session's grade results (`rubric_items_met`), else rubric item 0;
   - adds the student's known evidence or matched misconception text when there is one;
   - tells the tutor: ask ONE question that leads toward that item, state no rule and no
     definition, at most 60 words, do not request a teach-back.
2. **Student replies to a probe** (`INSTRUCT` and `instruct_step == "PROBE"`):
   - Grade with `focus_node_id = target` and `prior_context = "Tutor asked: <last tutor turn>"`,
     passing `student_id` and a new `call_id`, as the teach-back grade does.
   - `append_verdicts(..., Phase.INSTRUCT, focus_node_ids={target}, grader_call_id=...,
     content_version=..., source="probe")`, then yield the `grade` event.
   - Target `VERIFIED`: advance with the preface `Previous node "<title>" is VERIFIED on the probe.
     Congratulate in one sentence first.`
   - Target `PARTIAL`: `instruct_step = "EXPLAIN"`. The directive `ACTION=EXPLAIN` lists **only**
     the rubric items not in `rubric_items_met`.
   - `GAP`, `NOT_MENTIONED` or no verdict: `instruct_step = "EXPLAIN"`. The directive
     `ACTION=EXPLAIN` gives a full explanation from the canonical explanation and example, and
     corrects each matched misconception (quote its text).
   - Every EXPLAIN directive: under 120 words, end with one check question, do not request a
     teach-back.
3. **Student replies to an explanation** (`instruct_step == "EXPLAIN"`): set
   `instruct_step = "CONTINUE"`, then behave exactly as today's INSTRUCT turn
   (`instruct_turns_on_node += 1`, `_continue`, max-turns force).
4. **`instruct_step == "CONTINUE"`**: unchanged from today.
5. **Sentinel gating**: after the tutor turn, move to `TEACH_BACK` only when the filter found the
   sentinel **and** `instruct_step == "CONTINUE"`. Otherwise ignore it. The filter already strips
   it from speech, so nothing reaches the student.
6. **Teach-back failed, retry** (attempts left): `instruct_step = "CONTINUE"`, so the retry
   directive's sentinel is honoured as today.
7. **COMPLETE**: `instruct_step = None`.
