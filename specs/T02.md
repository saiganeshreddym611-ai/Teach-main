## Code

Import rule, to avoid circular imports: `contracts/*` may import from `tutor.models`.
`tutor/models.py` must **not** import from `tutor.contracts`.

Field lists below are binding: names, types and defaults. Use `BaseModel` from Pydantic v2.
`list[...] = []` defaults are fine in Pydantic (it copies them).

### `contracts/content.py`

```python
Sha256 = Annotated[str, Field(pattern=r"^[0-9a-f]{64}$")]
ReviewStatus = Literal["draft", "claude_reviewed", "needs_expert", "signed_off"]
DocType = Literal["standard", "study_material", "rtp", "mtp", "past_paper", "amendment"]
ClaimVerdict = Literal["supported", "contradicted", "not_found"]
USABLE_REVIEW_STATUSES: frozenset[str] = frozenset({"claude_reviewed", "signed_off"})

class ReviewerInfo(BaseModel):
    mode: Literal["session", "claude-api"]
    model: str = ""

class ReviewClaim(BaseModel):
    claim: str
    verdict: ClaimVerdict
    passage_id: str | None = None
    quote: str = ""
    quote_verified: bool = False

class ReviewMeta(BaseModel):
    status: ReviewStatus = "draft"
    content_sha256: Sha256
    reviewer: ReviewerInfo | None = None
    claims: list[ReviewClaim] = []
    report_id: str | None = None
    signed_off_by: str | None = None
    signed_off_at: datetime | None = None
    notes: str = ""

class ReleaseSignoff(BaseModel):
    pack_id: str
    version: str
    content_hash: Sha256
    signed_off_by: str
    signed_off_at: datetime
    scope_note: str = ""

class SourceDoc(BaseModel):
    doc_id: str
    doc_code: str                 # prefix of passage IDs, e.g. "IndAS115", "ICAI.SM.FR", "RTP.2025-05"
    title: str
    short_name: str = ""          # for citation labels, e.g. "Ind AS 115"; falls back to title
    doc_type: DocType
    issuer: str = ""
    authority_rank: int = Field(ge=1)   # 1 = most authoritative. Convention: standard and amendment 1,
                                        # study_material 2, rtp / mtp / past_paper 3
    attempt: str | None = None    # "YYYY-MM"
    version: str = ""
    path: str                     # relative to the pack root, e.g. "sources/raw/ind_as_115.txt"
    sha256: str = ""              # of the raw file; "" = not recorded yet
    license_note: str = ""

class Passage(BaseModel):
    passage_id: str               # f"{doc_code}.{locator}", e.g. "IndAS115.para.76"
    doc_id: str
    doc_type: DocType
    paper: str = ""
    chapter: str = ""
    section: str = ""
    locator: str                  # e.g. "para.76", "para.B28", "ch4.s2.p3", "q3", "q3.ans"
    attempt: str | None = None
    version: str = ""
    page: int | None = None
    text: str
    sha256: Sha256                # of `text`, UTF-8
    supersedes: list[str] = []    # amendments only: passage IDs this passage replaces

class Citation(BaseModel):
    passage_id: str
    label: str                    # e.g. "Ind AS 115, para 76"
    doc_id: str

class ScoredPassage(BaseModel):
    passage: Passage
    score: float
    confidence: float = Field(ge=0.0, le=1.0)

class PackManifest(BaseModel):
    pack_id: str
    exam: str
    paper: str
    attempt: str                  # "YYYY-MM"
    version: str                  # semver of the pack, e.g. "0.1.0"
    topics: list[str]
    doc_codes: dict[str, str] = {}   # doc_code -> doc_id in sources/sources.json
    out_of_scope_message: str = ""

class CorpusManifest(BaseModel):
    built_from: dict[str, str]    # doc_id -> sha256 of the raw file
    chunk_count: int = Field(ge=0)
    corpus_sha256: Sha256         # sha256 of corpus/chunks.jsonl bytes
```

### `contracts/skills.py`

Money, percent and date values are **strings** (`"1250000.00"`, `"12.5"`, `"2026-04-01"`) so
they stay exact. T51 parses them by `ParamSpec.type`.

```python
ParamType = Literal["money", "percent", "date", "int", "choice", "name"]

class ParamSpec(BaseModel):
    type: ParamType
    min: str | None = None
    max: str | None = None
    step: str | None = None
    choices: list[str] = []

class NumericCheck(BaseModel):
    type: Literal["numeric"]
    field: str                    # key in the answer key
    tolerance: str = "0"          # absolute, decimal string

class DiscrepancyCheck(BaseModel):
    type: Literal["discrepancy"]
    discrepancy_id: str

class JudgementCheck(BaseModel):
    type: Literal["judgement"]

RubricCheck = Annotated[NumericCheck | DiscrepancyCheck | JudgementCheck, Field(discriminator="type")]

class RubricItem(BaseModel):
    id: str
    text: str
    weight: float = Field(default=1.0, gt=0.0)
    node_id: str
    passage_ids: list[str] = []
    required: bool = False
    check: RubricCheck

class PlantedDiscrepancy(BaseModel):
    id: str
    row_id: str
    issue_type: str = Field(pattern=r"^[a-z_]+$")   # premature_revenue, duplicate_billing,
                                                    # missing_credit_note, wrong_period, ...
    node_id: str
    passage_ids: list[str] = []

class TaskDocument(BaseModel):
    doc_id: str
    title: str
    columns: list[str]
    rows: list[dict[str, str]]    # every row has a "row_id" key

class TaskTemplate(BaseModel):
    task_id: str
    skill_id: str
    title: str
    kind: Literal["calculation", "discrepancy_hunt"]
    node_ids: list[str]
    company: dict[str, str] = {}
    narrative_template: str
    params: dict[str, ParamSpec] = {}
    constraints: list[str] = []
    documents: list[TaskDocument] = []
    calculator: str               # registry key of the calculator (T51)
    answer_fields: list[str]
    rubric: list[RubricItem]
    planted_discrepancies: list[PlantedDiscrepancy] = []
    model_answer_template: str = ""
    pass_threshold: float = Field(ge=0.0, le=1.0)
    template_version: str

class TaskVariant(BaseModel):
    task_id: str
    seed: int
    params: dict[str, str]
    narrative: str
    documents: list[TaskDocument] = []
    answer_key: dict[str, str]
    answer_key_sha256: Sha256

class SkillDef(BaseModel):
    skill_id: str
    title: str
    description: str = ""
    task_ids: list[str]
    unlock_rule: Literal["all_tasks_passed"] = "all_tasks_passed"
```

Review status is **not** stored inside skills or tasks. It lives in the pack's `reviews.json`
(T11), keyed by `skill_id` or `task_id`.

### `apps/web/lib/contracts.ts`

One exported TypeScript type per Python model above, same names and field names (snake_case,
as they appear in JSON). Rules:

- `Literal[...]` becomes a string union type. `Enum` becomes a string union type.
- `X | None` becomes `X | null`. Fields with a default are optional (`field?: T`).
- `datetime` becomes `string` (ISO 8601). `dict[str, T]` becomes `Record<string, T>`.
- `RubricCheck` becomes a discriminated union on `type`.
- Import `NodeStatus` from `./api`. Do not import `contracts.ts` anywhere yet.

## Tests

`services/tutor/tests/test_contracts.py` (new).

| Test | Asserts |
|---|---|
| `test_example_validates[<Model>]` | Parametrised over every model above. Each has one realistic example dict in the test file. `Model.model_validate(example)` succeeds, and `Model.model_validate(obj.model_dump(mode="json")) == obj`. Example text is obviously synthetic (for example `"[TEST FIXTURE - NOT SYLLABUS TEXT] ..."`). |
| `test_bad_doc_type_rejected` | `SourceDoc` with `doc_type="blog"` raises `ValidationError`. |
| `test_bad_sha_rejected` | `Passage` with `sha256="abc"` raises `ValidationError`. |
| `test_rubric_check_discriminator` | A `RubricItem` with `check={"type": "numeric", "field": "revenue"}` parses to `NumericCheck`; `{"type": "guess"}` raises `ValidationError`. |
| `test_confidence_bounds` | `NodeVerdictV2` and `ScoredPassage` with confidence `1.5` raise `ValidationError`. |
| `test_old_ledger_event_still_valid` | A `LedgerEvent` built with only the pre-T02 fields validates, and has `kind == "concept"`, `source is None`, `passage_ids == []`. |
| `test_contracts_exports` | Every name in `tutor.contracts.__all__` is importable from `tutor.contracts`. |
