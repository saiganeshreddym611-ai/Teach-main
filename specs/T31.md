class LedgerNodeExport(BaseModel):
    concept_id: str; title: str

    confidence_score: float | None = None

## Rules that are not obvious

1. `LedgerStore` is the source of truth. `append_verdicts` appends each written event to
   `session.ledger` (this session's copy, shown in `SessionView.ledger`) and to the store.
   `store=None` means `ledger_store`, resolved at call time.
2. Every projection (status, confidence, mastery view, the state machine's node choice and
   "verified so far") uses `student_events()`. So a returning student is not re-taught verified
   nodes.
3. Keep today's rules: `NOT_MENTIONED` is never written; a VERIFIED node (from any session) is
   overwritten only by a verdict on a focused node. Extend the `append_verdicts` docstring:
   - a downgrade is explicit, from a focused verdict only (teach-back today; later probe, review,
     task remediation);
   - it is evidence-linked through `evidence_turn_id`, `grader_call_id` and `passage_ids`;
   - it is never incidental.
4. Every event gets `session_id`, `evidence`, `passage_ids`, `grader_call_id`,
   `content_version` and `source` (from `SOURCE_BY_PHASE`).
5. `GET /students/{id}/ledger` uses the active pack: `load_pack().curriculum` and
   `load_corpus(pack)`.
   - Each node's entry comes from its latest event, and the event list is the store's order.
   - Citation labels come from `cite_passage`. Skip passage IDs the corpus does not hold.
6. `GET /students/{id}/ledger/{event_id}/trace`:
   - Returns 404 when the event is not that student's.
   - Loads the session with `await store.get(event.session_id)`.
   - Returns the text of the turn whose id is `evidence_turn_id`, unchanged. Returns 404 when the
     session or the turn is missing.
   - Passages are the event's `passage_ids` that resolve in the corpus, in order.

## Tests (`tests/test_ledger_v2.py`)

| Test | Asserts |
|---|---|
| `test_cross_session_projection` | Student s1 verifies a node in session A. In a new session B (same student): `project_status(B)` shows VERIFIED, `B.ledger == []`, and `mastery_view(B)` shows VERIFIED. |
| `test_students_are_isolated` | Student s2 sees nothing from s1. |
| `test_returning_student_not_retaught` | Verify in the store the node `select_next_node` would pick first, then run a diagnostic in a new session (`ScriptedGrader`, no verdicts): the target is a different node. |
| `test_incidental_downgrade_blocked_across_sessions` | VERIFIED in A, then PARTIAL on a diagnostic in B: nothing written; still VERIFIED. |
| `test_focused_downgrade_recorded` | VERIFIED in A, then GAP on a focused teach-back in B with `grader_call_id="g1"`: one event with `source="teach_back"`, `session_id=B.id`, the evidence and `"g1"`; the status is GAP. |
| `test_event_fields_filled` | A `run_turn` diagnostic: every event has `source="diagnostic"`, `content_version == curriculum.content_hash`, `session_id`, and the `call_id` the grader received. |
| `test_export_status_mapping` | `export_ledger`: VERIFIED→MASTERED, GAP→GAP_IDENTIFIED, PARTIAL→PARTIAL, untouched→NOT_ASSESSED; the latest event's confidence and ts; one entry per node. |
| `test_ledger_endpoint` | API with mocks (the `test_api_mock.py` pattern): after one turn, `/students/s1/ledger` has every node and the raw events. |
| `test_trace_returns_exact_turn_text` | After a diagnostic turn with transcript T, the first event's trace has `student_turn == T` and a non-empty `grader_call_id`. |
| `test_trace_404_for_other_student` | The same event ID under `/students/other/...` returns 404. |
| `test_delete_student` | Removes only that student's events and returns the count. |
